# 🚀 ProjectFlow (Test_Project)

A modern, high-performance Project & Task Management Dashboard built with **React 19**, **Vite 8**, **Tailwind CSS v4**, and **IndexedDB**.

## ⚡ Features
- 📊 **6 Interactive Layout Views**:
  - **Dashboard**: High-level visual metrics & task trends.
  - **Kanban Board**: Drag/drop column status management.
  - **Gantt Chart**: Timeline scheduling & milestone tracking.
  - **Calendar**: Monthly/weekly deadline mapping.
  - **Table View**: Data grid with custom sorting and filters.
  - **Eisenhower Matrix**: Urgency vs. Importance priority matrix.
- 💾 **Local Database Persistence**: Automatic offline storage using `localforage` (IndexedDB) + JSON export & import.
- 🌗 **Light / Dark Mode**: Custom theme styling with dark mode integration.
- 👥 **Team Management**: Team member roles, avatars, and assignment tracking.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
